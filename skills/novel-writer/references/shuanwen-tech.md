# 爽文技巧（商业网文专属补充）

> 适用范围：商业网文模式的爽感结构。与 [commercial-mode.md](commercial-mode.md) 一起使用：commercial-mode 管平台结构与黄金三章，本文件管"爽感怎么造"。
> 经验来源：项目内《爽文写作技巧》1.md（爽文本质、代入感、情节反转）与 2.md（差异感、异性倾慕、低调装逼）。
> 冲突处理：本文件与 commercial-mode.md 冲突时，以更具体、更严格的一条为准；二者与代入感冲突时，代入感优先。

## 一、爽文本质与节奏

- 爽文是情绪，不是故事。读者要的是内啡肽快感；传统小说靠长铺垫，爽文要求每三五章一次转折。
- 快感节奏：每约 9000 字让读者体会一次完整快感；每个快感小故事控制在 1 万字以内，超过读者会不耐烦弃书。
- 情节反转 = "山穷水尽疑无路，柳暗花明又一村"的无限重复。反转前必须有"抑"的铺垫，且要有明确的"输了会失去什么"的代价。

## 二、四个爽感引擎

### 1. 差异感

| 类型 | 说明 |
| --- | --- |
| 地位差 | 主角身份低于装逼对象（普通人 / 末席弟子 vs 宗师 / 大人物），被高地位者冒犯或求上门。 |
| 信息差 | 只有主角知道的事（医术、情报、规则、金手指），碾压式爽点。 |
| 迪化 | 主角低地位/普通人，高地位配角不断脑补其强大、敬佩有加。 |
| 尊重感 | 高地位配角对低身份主角的尊敬本身即爽点。 |

- 毒点警告：能力与实际运用不匹配。已是金仙却跟凡人纠缠大半章、开局几个亿却只给父母几百块——毒。打脸对象的层级要与主角当前展示的身份匹配，或用合理冒犯解释。

### 2. 异性的倾慕

- 明恋、暗恋或若有似无的情愫都是无形爽点，同时是期待感加速器。要求平淡但频繁。
- 用法：非狗粮文作日常调剂桥段；狗粮文可作主爽点。
- 铁律：作调剂的女性角色永远不能落入其他配角手里，宁可神隐，不得写她谈恋爱、嫁人。其定位从登场就注定。
- 围绕权力、名声、金钱、爱情四点突出至少其二。

### 3. 低调装逼

- 主角被动装逼：不主动挑事，因利益矛盾被冒犯后，逐步露出强大让配角震惊。
- 公式：主角强大而厌倦世俗 + 反派因利益矛盾来冒犯 + 配角逐渐震惊 = 爽点、期待感。
- 一句话："我不想装逼的，但是你们一个个都在逼着我装逼。"
- 禁忌：无前置因果的路人莫名挑衅，属于低端爽点，削弱爽感。

### 4. 打脸四拍（当面完成）

1. 铺垫轻蔑：反派给出具体台词，明确看不起。
2. 反差展示：主角完成对方认定不可能的事，短而清楚。
3. 当面反馈：反派出现具体失态，具名情绪代理人说出反应（禁止"众人哗然"等无名反馈）。
4. 主角回应：给出短台词、决定或明确姿态，不以沉默转身代替收账。

## 三、利益前置的矛盾

- 反派的冒犯必须有利益因果（抢地、抢病人、砸招牌、夺宝、争名），不是莫名看主角不顺眼。
- 矛盾就是铺垫，铺垫越足，高潮越爽。
- 仇恨要明显：读者要清楚主角为什么非赢不可、输了会失去什么。
- 反派被压制时写明现实限制（忌惮、不确定、有人在旁、第二方案），不得无理由放过主角。

## 四、扮猪吃虎 12 拍节奏模板

受辱（积负面）→ 得金手指 → 释放小爽点 → 攒爽点 → 装逼释放 → 扮猪吃虎留悬念 → 不开眼的来冒犯 → 打脸 → 女神不知道我牛逼 → 女神面前装逼 → 女神倒贴但有更女神的 → 女神想倒贴而我却不愿意。

（不必机械套满 12 拍；按篇幅取 3~5 拍组成一个小弧线，核心是"抑→扬→留悬念"循环。）

## 五、反派与配角纪律

- 反派被打脸后保留后续行动：放狠话、带人再来、记仇、留第二方案，不得无理由消失。
- 被打脸者可为后续的"见证者/传话筒"——他知道主角牛逼，给主角未来的装逼机会。
- 具名情绪代理人与配角基于自身利益说话，允许说谎、拒绝、误解，禁止轮流给主角递信息。

## 六、代入感文本规范

与 [writing-and-revision.md](writing-and-revision.md) 互补：

- 形容词少，不用大段景物/回忆开场。
- 短句、勤断句，段落尽量 ≤80 字。
- 避免错别字、生僻字、标点错误、常识错误。

## 七、爽感自检（大纲、节拍完成后逐条过）

- [ ] 每 9000 字内有一次完整快感，快感小故事 ≤1 万字？
- [ ] 每个反转前都有"抑"的铺垫，且有明确的"输了会失去什么"？
- [ ] 每次打脸都有利益前置因果，没有莫名挑衅？
- [ ] 打脸时轻蔑者在场，给具体失态，有具名情绪代理人反馈？
- [ ] 主角全程被动装逼（"是你们逼我"），没有主动挑事？
- [ ] 能力与运用匹配，没有"高能力做低运用"的毒点？
- [ ] 有没有一处"异性倾慕"的日常调剂钩子？
- [ ] 反派保留第二方案或写明现实限制，没有无理由放过主角？
- [ ] 章末钩子是具体事件，不是"他不知道的是"式廉价悬念？
