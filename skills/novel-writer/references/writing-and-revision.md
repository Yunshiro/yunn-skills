# 正文创作与分层润色

## 目录

- 动笔前
- 正文规则
- 单章验证
- 分层润色
- 人工终检

## 动笔前

读取已确认的角色 DNA、大纲和当前章节节拍。长篇还要读取进度与记忆文件。先按目标字数设计场景拍子，每 250 至 300 字左右完成一个信息、动作或情绪变化。

不要先写短稿再补段。剧情量不足时从下一章借入事件，不用环境、回忆、设定解释或重复心理活动注水。

## 正文规则

### 字数与文件

- 按去掉标题和空白后的含标点字符计数。
- 单章目标允许上下浮动 200 字。
- 保存为 `output/章节正文/第N章·[章节标题].md`。
- 除章节标题外不使用 Markdown 引用、列表、表格、加粗或代码标记；投稿平台通常不解析这些语法。

### 视角与节奏

- 锁定当前视角人物，不写其无法感知的信息。
- 按“动作、人物反应、必要解释、新冲突”组织主要段落。
- 每个剧情节点都改变行动、信息、关系或情绪中的至少一项。
- 保留危险判断、计划、欲望和即时感受；删除复述刚发生事件的心理总结。
- 超字数时依次删纯环境、重复心理、重复情绪和解释性旁白，不删核心冲突与对话。

### 对话

- 让职业、阶层、年龄和利益决定用词与句长。
- 避免所有角色使用同一种完整、理性、解释充分的说话方式。
- 让人物隐瞒、误解、抢话、改口或拒绝，但不要用无意义停顿拖延信息。
- 威胁必须带现实后果；证据本身就是反击，不用空泛狠话。

### 去 AI 味

- 避免高频模具：眼神冰冷、嘴角勾起、身躯一震、倒吸凉气、心中掀起惊涛骇浪、前所未有、一字一顿、全场死寂、落针可闻、杀意弥漫、殊不知、旋即、就在这时。
- 控制“不是 A，是 B”“连……都/也”“没有 A，没有 B”等工整模板。
- 不连续使用相同数字量词，不默认凡事列三项。
- 不连续堆叠单句段，也不写三段以上超长段落。
- 不机械复用角色档案里的标志动作。
- 不用“你自己想”“你会知道的”“我不解释”代替有效回应。
- 不让配角轮流递信息，不让反派无理由放过主角，不让能力一次给完全部答案。

### 逻辑核算

在大纲中维护计量标准：重量换算、载重、速度、单人负重、价格基准等。每章核算距离除以速度、数量乘以单重、容器容量和能力边界。若角色来不及核实信息，写足时间、地形、监视或风险条件。

## 单章验证

每章保存后运行统一脚本：

```bash
python3 <skill-dir>/scripts/check_novel.py chapter \
  "./output/章节正文/第N章·标题.md" \
  --target 2500 \
  --hero "主角名"
```

机械指标失败时先根据报告修改，再重新运行。脚本通过后仍必须人工通读，因为它无法判断：

- 读者是否真正站在主角身体里。
- 模具句是否以脚本未收录的形式出现。
- 配角是否为主角服务、反派是否降智。
- 数字、空间、动机与因果是否可信。
- 对话是否同声同气。
- 情绪是否通过重复动作机械表达。

## 分层润色

严格按顺序执行，避免后一层破坏前一层目标：

### 1. 代入感润色

先做加法。把场外报道改成视角人物的所见所闻所感；为核心事件补即时情绪和必要身体感；补少量符合人物经历的人味句。不要改变剧情、人物关系和章末事件。

### 2. 去 AI 味润色

再做减法。删除模具句、工整对照、机械排比、重复数字、档案式人物介绍和复述性心理活动。保留上一层补入的有效感知与情绪。

### 3. 节奏压缩

合并重复信息，缩短不改变局势的来回对话，删除无功能环境和解释。每个场景保留进入理由、冲突变化和离开后的新局面。

### 4. 对话优化

检查身份差异、潜台词、利益和信息变化。让重要对话具有攻防，不用整齐的一问一答。

### 5. 环境与心理

让环境参与线索、阻碍、身份或情绪；让心理活动承担判断、欲望或即时反应。删除纯装饰环境和已经被动作表达过的重复解释。

## 全稿检查

完成全部章节后运行：

```bash
python3 <skill-dir>/scripts/check_novel.py manuscript \
  "./output/章节正文" \
  --hero "主角名"
```

如果每章目标字数相同，增加 `--target 2500`。机械指标通过后：

1. 随机连续读三章，判断自己是在主角身体里还是在旁边看。
2. 单独阅读第一章前 800 字，检查普通人的弱、核心机制和身体感官。
3. 抽出所有章末，检查是否连续使用相同钩子结构。
4. 找出全书三个最大情绪节点，确认反馈人物有名有姓且行为一致。
5. 验算所有距离、时间、重量、价格和能力限制。
6. 朗读全文；读不顺、像标语或没有新信息的句子继续修改。
